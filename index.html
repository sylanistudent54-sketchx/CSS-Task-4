CSS Task 4 — Padding, Border, Content Width and Height

Understanding the Box Model

Every HTML element is displayed as a rectangular box. The CSS Box Model consists of content, padding, border, and margin.

1. Different Padding and Border Values

The content width is kept at 200px. Padding and border values are changed to observe the total box size.

Box 1 — Small Values

Content
200px wide

Padding: 10px

Border: 2px solid

Content

Box 3 — Large Values

Content
200px wide

Padding: 40px

Border: 8px solid

2. Different Height Values

The width, padding, and border remain the same. Only the content height changes.

Short Box

Height: 60px

Medium Box

Height: 120px

Tall Box

Height: 180px

What I Observed

  • Increasing padding creates more space between the content and the border.
  • Increasing border width makes the border thicker and increases the total size of the box.
  • Increasing content width or height changes the dimensions of the content area.
  • The default box-sizing: content-box means padding and border are added outside the declared content width and height.
